# Transmission Database System

This repo serves as the place to find the source code for the front end of our Information Management Project

### Currently this Frontend Prototype has the following
- Basic Login with dummy accounts
- Views for Preparer, Receiver and Approver
- Views for Creating Records and Transmissions, as well as editing said things
